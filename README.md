# Riverside College — React School Website

A responsive, multi-page school website starter built with React, TypeScript, Vite, TanStack Router and Lucide React.

## Features

- Responsive navigation with mobile menu
- Home, About, Academics, Admissions, Campus Life, News & Events, and Contact pages
- Reusable program cards and section headings
- Admissions and contact form validation with demo success states
- News category filters
- Custom responsive CSS, semantic HTML and accessible labels
- Custom 404 page

## Run locally

1. Install Node.js (LTS) if you have not already.
2. Extract this folder and open it in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL Vite prints in your terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Before using this as a real school website

- Replace the fictional school name, contact information, school facts, dates and testimonials.
- The contact and admissions forms are front-end demos only. Connect them to a secure backend or form service before collecting real information.
- Replace the Unsplash image URLs with approved school photography if needed.
- Add privacy policy, safeguarding information and any locally required school notices.
- Configure your deployment host to serve the SPA entry point for nested routes.
